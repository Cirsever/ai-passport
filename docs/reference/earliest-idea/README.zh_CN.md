# AI Passport 最早想法

这是项目最早的产品方向，后续设计应持续把它作为长期参考。

![AI Passport 最早概念](../../../assets/images/ai-passport-earliest-concept.png)

当前项目有意采用像素风格。那是展示语言的选择，并不代表底层交互方向发生变化。后续页面和状态变化仍应持续参考这套概念：

- 让 AI 伙伴的状态和上下文清晰可见；
- 明确呈现等待、同步、创作、聆听、完成等状态变化；
- 让可组合的能力模块服务于有意义的工作流；
- 同时考虑随身使用和桌面使用等场景；
- 保持信息适合快速浏览，并让用户感受到过程在推进。

图片是方向性参考，不是已经确认的硬件规格、文案方案或实现契约。新提出的细节仍应单独确认并记录后，才能视为正式需求。
